# projectNifi

Java Spring Boot project.

## Stack

- Java 21
- Spring Boot 3.5.0
- Maven
- Spring Web, Spring Data JPA, H2 (in-memory database)

## Prerequisites

- JDK 21 (`JAVA_HOME` should point to a JDK 21 install, e.g. `/usr/lib/jvm/java-1.21.0-openjdk-amd64`)

## Running

```bash
./mvnw spring-boot:run
```

## Testing

```bash
./mvnw test
```
